# Script Catalog

このカタログは公開対象の現行ファイルだけを記載します。`lib/` 内のファイルは単独実行用ではなく、対応するエントリーポイントから `#include` される内部ライブラリです。

## Transform tools

### `scripts/angle-reset/angle-reset.jsx`

- 役割: 選択オブジェクトの回転、シアー、拡大縮小を必要に応じて解除します。
- 対応対象: 配置画像、ラスタ画像、クリッピンググループ、グループ、テキストフレーム、四点の閉パス、二点の開パスです。
- 動作: ScriptUI ダイアログで対象種別と解除する変形を選び、行列演算とバウンディングボックスの再計算を使って変形を補正します。
- 注意: オブジェクトの構造や効果により完全に同一の外観を保証するものではありません。保存済みの複製ファイルで確認してください。

## Curve tools

### `scripts/curve-converter-v2/curve-converter-v2.jsx`

- 種別: 実行用エントリーポイント。
- 役割: 選択した長方形または凸多角形のコーナーを曲線へ置換します。
- 曲線種別: スーパー楕円（Lamé）、G2 曲率連続、クロソイド、G3 曲率連続です。
- 動作: 角単位の選択、プリセットと値の入力、ライブプレビュー、キャンセル時のスナップショット復元を提供します。スーパー楕円は軸整列した長方形に限定されます。
- 依存: `lib/math-engine-v2.jsx`。

### `scripts/curve-converter-v2/lib/math-engine-v2.jsx`

- 種別: `curve-converter-v2.jsx` 専用の内部ライブラリ。
- 役割: 長方形・多角形の解析、パスのスナップショットと復元、スーパー楕円点列と各種コーナー曲線の計算を行います。
- 動作: Illustrator DOM の書込みを持たない計算部と、パス点を安全に置換するためのデータ表現を提供します。

### `scripts/curve-optimizer/curve-optimizer.jsx`

- 種別: 実行用エントリーポイント。
- 役割: 選択した編集可能パスの指定アンカーに G2 曲率連続補正を適用します。
- 動作: 補正率・形状変化・対象アンカー・曲率コムの表示をダイアログから指定し、プレビューと最終適用を分離します。必要なら元パスを複製して残せます。
- 依存: `lib/math-engine.jsx`。

### `scripts/curve-optimizer/lib/math-engine.jsx`

- 種別: `curve-optimizer.jsx` 専用の内部ライブラリ。
- 役割: ベジェ曲線の微分と曲率計算、G2 ハンドル補正、曲率コム用のサンプリング、パスのスナップショットと復元を提供します。
- 動作: Illustrator DOM に依存しない数値計算を中心にし、エントリーポイントが結果をパスへ適用します。

## Production tools

### `scripts/artboard-name-from-filename/artboard-name-from-filename.jsx`

- 役割: 保存済みAIファイルのファイル名を、アートボード名に反映します。
- 動作: アートボードが複数ある場合は2桁以上の連番を付け、変更中のエラー時は元の名称へ戻します。
- 注意: ファイル名を取得するため、先にAIファイルを保存してください。

### `scripts/artboard-submission-info/artboard-submission-info.jsx`

- 役割: 各アートボードの名称を元に、入稿情報のテキストを作成します。
- 対象: アクティブドキュメント内のすべてのアートボードです。
- 動作: フォントサイズ15 ptで、各アートボード左上から横・縦とも10 mmの位置に配置します。トリムマークは作成しません。
- 注意: Illustrator内のテキストとレイヤーを変更するため、事前に複製ファイルで確認してください。

### `scripts/trim-marks/trim-marks.jsx`

- 役割: 選択オブジェクトの `geometricBounds` を基準にトリムマークを生成します。
- 入力: トリムマークの間隔（mm）と出力先レイヤー名です。
- 動作: 四隅と各辺中央のマークをグループ化し、レジストレーションスウォッチがあればそれを、なければ CMYK 100% を線色に使います。生成レイヤーは完了後にロックされます。
- 注意: 選択した各オブジェクトごとにマークを生成します。

### `scripts/layer-order-by-position/layer-order-by-position.jsx`

- 役割: 同じ親レイヤーまたはグループ内にある選択オブジェクトを、視覚上の位置に合わせて重ね直します。
- 入力: 同じ親を持つ 2 個以上の選択オブジェクトです。
- 動作: `visibleBounds` の上端を優先し、同じ高さでは左端を比較してソートします。下側のオブジェクトから前面へ移動し、上側が前面になる順序にします。
